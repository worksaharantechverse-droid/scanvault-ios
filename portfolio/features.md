# Features — ScanVault

## Verified in the iOS 26 simulator

- Document list with search across titles and recognized text.
- Add flow with Photo Library import and automatic OCR.
- Detail view with large image, editable title and recognized text.
- Delete and system share actions.
- Demo mode seeded by the `-UITestDemo` launch argument.
- Light and dark appearance.

## Verification note

Unit and UI tests are authored and compile, but execution was skipped at the user's request.
